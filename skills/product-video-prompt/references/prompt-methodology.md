# 商品视频 Prompt 约束方法论（供叙事 prompt 参考）

> 本文档是撰写叙事型商品视频 prompt 时的**约束工具箱**。
> 叙事是骨架，约束是关节——有约束的叙事才稳定可生成。

---

## 核心定位

商品视频 prompt 同时需要两层：

- **叙事层**（主体）：人物、场景、情节、情绪、叠字文案、CTA
- **约束层**（骨架）：把产品的外观和关键结构锁死，防止生成模型"重新发明产品"

本文档聚焦约束层——讲故事的思维不在这里，但写故事时每段都要顺手把约束绑上去。

---

## 约束的三个核心原则

### 1. 外观一致性锁

产品在全片每一帧的外观必须完全一致。生成模型天生会"漂移"——颜色变深、logo 消失、多出不存在的扣子。

**写法**：在"全局约束"段落里，列出所有视觉锚点，并绑定参考图。

```
【全局约束 — 外观一致性】如参考图一，整个视频中{产品名}必须前后一致：
{精确颜色}、{具体材质}、{标志性设计元素}、{logo 位置和内容}。
不可凭空出现新的结构部件。
```

### 2. 关键结构/机制锁

如果产品有特殊机制（开合、变形、折叠），必须说清楚：
- 机制由哪些部件构成
- 闭合/展开分别是什么状态
- 每个状态对应哪张参考图

```
【全局约束 — {机制名}】{产品}采用 {机制描述}：
{部件} 从 {位置A} 到 {位置B}。
闭合状态 = 参考图X，展开状态 = 参考图Y。
```

### 3. 叙事内嵌约束

在分段叙事里描述动作时，顺手加上物理/几何约束，避免动作描述太语义化：

- ❌ "她拉开拉链" → 动作方向不明确
- ✅ "双手同时从鞋口向鞋头方向拉下两侧拉链，两条拉链同步滑动"

- ❌ "鞋子打开" → 状态不明确
- ✅ "鞋口敞开，露出鞋垫（参考图二展开状态）"

关键是：**动作 = 路径 + 同步性 + 结果状态**，而不是一个抽象动词。

## 进阶约束 pattern（针对复杂机械结构）

以上三条是基础。如果产品有非常规机械结构（开合、变形、折叠、旋转），只用基础约束往往不够——模型会按自己的想象补全。下面三条 pattern 是实战踩坑后总结出来的加固工具。

### Pattern A：几何拓扑描述（取代动作描述）

把机械结构描述成**几何拓扑**——起点、路径、终点、对称性——而不是描述动作。

- ❌ "a zipper runs around the shoe" → 模糊，模型会按常见对称模式补全
- ✅ 明确给出：
  - **START point**：具体位置（`top of the collar on ONE side, next to the heel cup`）
  - **PATH**：方向序列（`DOWN that side → AROUND the toe → UP the OTHER side PARTWAY`）
  - **END point**：具体位置（`a LOW/MID point on that side, well below the collar`）
  - **对称性**：明确说是对称还是非对称（`the two endpoints are NOT symmetric`）

适用场景：任何拉链、链条、轨道、折叠线的描述。

### Pattern B：显式禁止常见误解（Negative Structural Constraints）

**识别模型最可能产生的错误联想，然后显式禁止**。这一条能救命——模型对"看起来可能动"的部件天生有动的冲动。

做法：
1. 想象模型会把什么部件幻想成可动/可开
2. 用大写/加粗强调："X is fully CLOSED and rigid... X CANNOT open, split, or flex apart"
3. 把**装饰性元素**和**功能性元素**显式区分（"The heel pull tab is decorative only — it does NOT indicate any opening"）

例子：
- 鞋子的后跟看起来像可以打开 → 显式声明"heel is a solid continuous piece, no seam opening at the back"
- 手表的表冠看起来像能按 → "crown is decorative on this model, does not rotate or pull out"
- 包的提手看起来像能拆 → "handle is permanently sewn, does not detach"

### Pattern C：跨段状态连续性锁

一个 prompt 有多个段落时，模型会"自己补全段间逻辑"——结果可能是人物凭空穿上鞋、换了件衣服、脚换了一只。**必须在每段开头或关键节点显式锁定起始状态**。

做法：
- 开场段明确起始状态：`both feet in socks only, NO shoes on at all`
- 每个关键段在动作开始前重申：`before this moment, her right foot is still bare-socked only`
- 重要的空间/方位关系要复述：`the zipper is at the outer side of the shoe`

尤其在"穿上/摘下/改变"类动作前后，必须显式说清楚"之前是什么样、之后是什么样"。

### Pattern D：单次演示原则（只演示一次完整动作）

对"需要做两次的动作"（例如穿两只鞋、戴两只耳环、扣两排扣子），**不要在 15 秒里强行塞入两次完整演示**。实测 Seedance 处理重复动作时会偷懒跳过中间步骤——比如第二只鞋不拉开就直接穿进去。

做法：
- 只完整演示**一只脚 / 一只耳朵 / 一侧** 的全过程
- 另一侧要么**始终维持在起始状态**（如左脚保持袜子状态不穿鞋），要么**不出现在画面里**
- 结尾 CTA 不要求"两只都穿好"的全身走路镜头——改为坐着的特写、手部特写、或只有单侧入镜的镜头

例子：
- ❌ "她穿上第一只鞋，然后重复同样的动作穿上第二只鞋" → 第二只必翻车
- ✅ "她演示穿右脚的完整过程，左脚始终保持袜子状态，结尾是她坐在沙发上看着穿好的右脚满意地点头"

原理：模型对"重复演示"的理解很弱——它会认为第二次是装饰性的、可以简化。与其让它简化出错，不如主动砍掉重复部分，把镜头时间留给一只脚的完整叙事。

### Pattern A 补充：整体性约束（One Single Piece）

Pattern A 讲了起点/路径/终点，但还不够——模型对"一大块会变形的面板"经常理解错。要显式声明**可变形部分是一整块连体**，否则它会拆成两瓣。

做法：
- 列出所有属于"上盖"的子部件
- 用 `as ONE single connected piece` / `as a single rigid panel` 强调
- 明确变形轴：`hinges AT {具体位置}` / `rotates around {某轴}`
- 禁止错误变形：`does NOT split into two halves` / `does NOT separate at the center`

例子：
```
When unzipped, the FRONT upper — toe cap + vamp + both side panels + tongue + 
laces — as ONE single connected piece, hinges AT THE TOE and folds forward.
The upper does NOT split into left-half and right-half. It does NOT separate 
along the tongue centerline. It moves as one rigid clamshell lid.
```

### 这三条何时必须用（更新）

- 产品有任何非对称机械结构（非对称拉链、单侧铰链、不规则折叠）
- 产品有"看起来像但实际不是"的元素（装饰带、固定扣、装饰缝线）
- 产品有可翻折/变形的大面板（用 Pattern A 补充的整体性约束）
- 视频中人物状态会变化（穿上/脱下、换场景、改变姿势）
- 视频涉及"做两次"的动作（穿两只鞋/戴两只耳环等）→ 用 Pattern D 砍掉重复

简单产品（一个水杯、一支口红）不需要用这些，会让 prompt 过度约束。

## 生成模型的能力边界（非常重要）

Seedance / Runway / Pika 这类文生视频模型不是 3D 引擎。写 prompt 前要清楚它们的能力天花板，避免让它们做做不到的事。

### 能做好的

- 单一主体的自然运动（人走路、物体旋转、布料飘动）
- 常见物理动作（倒水、手拿起物体、脚步移动）
- 镜头运动（推拉摇移、环绕、跟拍）
- 光影变化、氛围渲染
- 场景/人物切换（只要每段独立，别在同一段内切来切去）

### 做不好 / 会翻车的

- ❌ **非常规机械结构的详细变形过程**：比如 BILLY 鞋的"鞋面像书本翻折"——模型从未见过这种运动，强行描述会生成错乱的形态。**对策**：不要用文字描述机制变形过程，只描述起始和结束状态，用参考图绑定
- ❌ **同段内多主体复杂协同**：手 + 脚 + 产品在同一段内各自做复杂动作 → 必翻车。**对策**：一段只有一个主要动作主体
- ❌ **同段内多次状态切换**：A→B→C 在一段里做完 → 中间态崩坏。**对策**：一段只做一次 A→B 转变
- ❌ **物体朝向突变**：脚从上方踩入容易让模型搞反鞋和脚的朝向。**对策**：避免从正上方介入产品的复杂方位动作，或者用侧向、斜向角度替代
- ❌ **同段内镜头剧烈切换**：一段里从侧面切俯拍再切回 → 模型混乱。**对策**：一段一个镜头角度，切换发生在段与段之间

### 把这些边界落到叙事里

叙事的"感觉"不需要靠复杂动作实现，可以靠：
- 节奏对比（慢镜头 vs 快切）
- 镜头语言（低角度=力量感、俯拍=全局感、跟拍=代入感）
- 光线氛围（晨光=希望、暖灯=温馨、冷调=酷感）
- 叠字文案（一句话顶很多画面）

## 参考图的正确用法

参考图是最强的约束——比任何文字都管用。

**必须做的**：
- 给每张参考图编号（参考图一、参考图二...）
- 在全局约束里明确"如参考图X"
- 在分段叙事里绑定该段产品状态对应哪张图
- 关键状态（闭合/展开）必须有对应参考图

**不要做的**：
- 堆砌大量参考图——3-5 张关键图就够，多了模型反而抓不住重点
- 让参考图之间视觉差异过大（比如不同颜色的同款）——会让模型以为是不同产品

---

## 约束 ≠ 僵硬

约束不等于取消创造力。好的叙事 prompt 是：

> 在锁住"产品该是什么样"的前提下，让人物和场景自由发挥

产品外观 = 硬约束（不许变）
人物、场景、光线、节奏、情绪 = 软约束（可创作）

这样模型既能稳定复现产品，又能拍出有感染力的广告片。
